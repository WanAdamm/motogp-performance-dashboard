# Circuit Artwork

These SVGs are adapted from the Wikimedia Commons files listed below. Each map was cropped
to the circuit, stripped of labels and unrelated artwork, and recolored for the dashboard.
The adapted SVG remains available under its source license; application code is licensed
separately. The source SVGs were not taken from the Dorna timing PDFs.
